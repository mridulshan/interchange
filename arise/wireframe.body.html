    What turns this wireframe into the real thing

    1. Write S07 first — the message. Everything else is framing for it.
    2. Shoot or pick 4 photos: dim/candid, portrait 3:4, the licence photo, and the S02 hero pose.
    3. Build the S02 sequence: 180 frames, ffmpeg -i clip.mp4 -vf fps=30,scale=1600:-1 -q:v 6 f_%03d.jpg
    4. Swap the procedural draw for the decoded image array — index maths is unchanged.
    5. Fill every amber slot on the page.
    6. Ship it static — any host will do. One URL, works on his phone.
